# Netrunner móvil

Versión móvil del panel Netrunner (Expo + React Native + TypeScript + expo-router), con la estética HUD del panel de escritorio.

## Arrancar

```
npm install
npx expo start
```

Abre el código QR con Expo Go.

## Configuración

El ID de la app registrada en Microsoft va en `.env`: copia `.env.example` a `.env` y rellena `EXPO_PUBLIC_MS_CLIENT_ID`.
